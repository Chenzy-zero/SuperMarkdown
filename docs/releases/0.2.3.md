# SuperMarkdown v0.2.3

左侧文件目录现在跟随当前正在编辑的文件。

## 下载

- `SuperMarkdown-0.2.3-windows-x64-setup.exe`：Windows 64 位安装包。
- `SuperMarkdown-0.2.3-windows-x64.zip`：完整解压后运行 `SuperMarkdown.exe`。
- `SHA256SUMS.txt`：附件校验值。程序包尚未进行代码签名。

## 更新

- 点击文件标签，左侧切到该文档的父目录并高亮对应文件。
- 双文件并排时，点击左侧或右侧编辑区，目录跟随该侧当前文档；内容、撤销记录和未保存修改保持不变。
- 目录读取只响应文件激活，不在输入时反复刷新；同目录的切换保留展开及滚动状态。
- 快速切换多个文件时，以最后激活的文件为准，过时的异步结果或错误不会切回旧目录。
- 未命名文档保留最近浏览位置；手动打开另一个文件夹可先浏览，重新激活文档后再跟随。
- 目录同步不会抢走正文焦点，也不会把已选择的“大纲”强制切回“文件”；返回文件视图时显示已同步的目录。

## 验证

真实进程检查覆盖标签切换、左右区域点击、右侧标签激活、快速交替切换及未保存内容保护；另检查异步目录先后顺序并回归现有编辑、保存、分屏和草稿恢复功能。
