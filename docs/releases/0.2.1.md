# SuperMarkdown v0.2.1

修复安装后缺少 Markdown 文件关联，以及从资源管理器双击文档只启动软件、未载入对应内容的问题。

## 下载

- `SuperMarkdown-0.2.1-windows-x64-setup.exe`：Windows 64 位安装版。
- `SuperMarkdown-0.2.1-windows-x64.zip`：完整解压后运行，无需另外安装运行环境。
- `SHA256SUMS.txt`：附件校验值。程序包尚未进行代码签名。

## 修复

- 安装包注册 `.md`、`.markdown`、`.mdown`、`.mkd`，同时注册到 Windows 默认应用候选列表，打开命令正确引用 EXE 和文档路径。
- 安装完成页提供打开默认应用设置的选项，软件左下方也增加同一入口。Windows 需要用户在系统界面确认默认应用一次，安装程序不会绕过已有的用户选择。
- 首次启动会读取系统传入的文档路径；软件已运行时，第二个进程会把路径转交给现有窗口并打开标签页。
- 支持中文、空格、相对路径及多个文件；编辑器未就绪或正在提示恢复草稿时，请求先排队。
- 重复打开已经编辑的文档复用标签页，保留未保存内容；无法读取的文件显示错误且不关闭当前文档。
- 修正空工作区的初始文档索引，确保恢复的源码模式和首个非 Markdown 文件的编辑模式保持正确。

## 设置默认应用

安装后，在默认应用设置中搜索 `.md`，选择 SuperMarkdown；也可右键 `.md` → 打开方式 → 选择其他应用 → SuperMarkdown → 始终。已经选择 SuperMarkdown 的用户升级后可直接再次双击文档。

ZIP 版不会写入安装关联；可通过“打开方式”选择完整解压后的 `SuperMarkdown.exe`。

## 验证

系统打开流程在独立配置目录使用真实进程验证：冷启动、软件已运行、中文/空格和相对路径、重复打开保留修改、文件不存在、恢复提示等待及恢复后复用标签。另回归文件保存、分屏与草稿恢复。自动检查不修改当前用户的默认应用选择；实际 Windows 默认应用确认仍由用户完成。

参考：[Windows 默认应用要求](https://learn.microsoft.com/en-us/windows/compatibility/file-type-and-protocol-associations-model)、[Electron 启动参数与单实例事件](https://www.electronjs.org/docs/latest/api/app)。
