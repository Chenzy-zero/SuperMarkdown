# SuperMarkdown v0.1.0

Windows 64 位 Markdown 可视编辑原型，首次公开打包版本。

## 下载与运行

- `SuperMarkdown-0.1.0-windows-x64-setup.exe`：安装版，可选择安装位置并创建桌面快捷方式。
- `SuperMarkdown-0.1.0-windows-x64.zip`：解压版，完整解压后运行其中的 `SuperMarkdown.exe`。不要只取出单个 EXE。
- 两种包均包含运行环境，不需要另外安装 Node.js、pnpm 或 Electron。
- `SHA256SUMS.txt` 提供附件的 SHA-256 校验值。

## 本版功能

- 打开本地工作文件夹，浏览子目录及 Markdown、TXT、代码等文本文件。
- Markdown 可视编辑、源码切换及共享撤销历史；其他文本文件按纯文本编辑。
- 左侧文件目录右键操作，直接创建空白 `.md` 文件且不覆盖同名文件。
- 双文件并排、左侧可视编辑与右侧源码双向同步，拖动中间分隔条调整宽度，双击恢复等宽。
- Markdown 两种模式使用统一的居中阅读宽度与留白。
- 文件标签页关闭和右键菜单，`Ctrl+W` 关闭当前文档并提示未保存修改。
- 大纲跳转、表格操作浮层、完整的工具栏提示，以及鼠标右下方链接目标提示和本地/网页链接跳转。

## 使用前请了解

**本版是技术验证原型，尚未实现将正文修改保存回文件。输入内容仅保存在当前窗口中，关闭前请复制保留。新建操作会实际创建空白 Markdown 文件，但随后输入的正文不会自动写入。**

- 尚未提供图片落盘、草稿恢复、外部修改监听、查找替换及自动更新。
- 中文输入法、复杂 Markdown 往返及光标定位仍需继续验证。
- 安装包未进行代码签名，Windows 可能提示发布者未知。
- 本次在当前 Windows x64 环境验证，未完成所有目标 Windows 版本的兼容性测试。

## 验证

发布前在真实 Electron 编辑器及打包后的应用中执行完整界面回归；覆盖目录、文本打开、编辑历史、链接、分屏同步、快捷关闭和拖动布局。构建及验证说明见仓库 README。
