# SuperMarkdown v0.4.0

增加文档统计、编码菜单和左右文件差异对比。

## 下载与升级

- `SuperMarkdown-0.4.0-windows-x64-setup.exe`：Windows 64 位安装包，沿用原目录直接覆盖升级。
- `SuperMarkdown-0.4.0-windows-x64.zip`：完整解压后运行 `SuperMarkdown.exe`。
- `SHA256SUMS.txt`：附件校验值。程序包尚未进行代码签名。

升级前保存文档并关闭旧版，无需先卸载。

## 文档统计

底部显示活动文件的总行数、总字符数和当前编码；切换左右编辑区时跟随对应文件。统计随输入、撤销和重新载入更新，按 Markdown 源文计入语法标记、空格和换行。空文档为 1 行，末尾空行计入总行数；Unicode 字符按码点计数，CRLF 与 LF 的换行均计一个字符。

## 编码菜单

点击底部编码名称，或选择“文件 → 文件编码…”。提供“转换后保存”和“按指定编码重新读取”两种操作：

- UTF-8、UTF-8 with BOM、UTF-16 LE / BE。
- ASCII、GBK、GB18030、Big5、Windows-1252、ISO-8859-1（Latin-1）。

转换会保存当前编辑内容，仍执行外部修改冲突检查。所选编码无法容纳中文或其他字符时拒绝写入，原文件完整保留；不会将字符静默替换成问号。未命名文档先选择保存位置。

重新读取不写入磁盘，当前有未保存内容时需先保存。无 BOM 编码可能有歧义，纯 ASCII 字节自动识别为 UTF-8 也属正常；本次窗口明确选择的编码用于后续保存。

## 左右文件比较

在“双文件并排”中打开两篇不同文档，点击路径栏“比较左右文档”，或选择“查看 → 比较左右文档”。

- 使用当前内容，包括未保存修改；Markdown 比较其源文，代码和 TXT 也可比较。
- 两侧显示行号、差异行和行内变化，左侧红色、右侧绿色。
- 分别统计新增、删除和修改的差异块；相同文档明确显示无差异。
- F7 / Shift+F7，或上一处 / 下一处按钮定位差异，并滚动到对应位置。
- 比较视图只读；“返回编辑”保留两侧布局、模式和修改，不执行合并或写回。

比较忽略 Windows / Linux 的换行格式差异，保留其他空白差异。复杂大区域在计算预算内无法精细分割时按块显示并提示；不是 Beyond Compare 的完整替代。同篇文档的预览源码同步布局不启用双文件比较。

## 验证

覆盖十种编码的字节与 BOM 往返、中文不可编码保护、编码重新读取与磁盘冲突；检查活动文件统计、未保存文档比较、新增/删除/修改、长文跳转、只读保护及窄窗口状态栏，并回归保存、恢复、主题、缩放、多行输入与系统文件打开。

差异组件采用本地 [CodeMirror Merge](https://github.com/codemirror/merge)，不需要网络服务。
