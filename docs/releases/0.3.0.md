# SuperMarkdown v0.3.0

本次更新集中在菜单布局、代码编辑与主题。

## 下载

- `SuperMarkdown-0.3.0-windows-x64-setup.exe`：Windows 64 位安装包。
- `SuperMarkdown-0.3.0-windows-x64.zip`：完整解压后运行 `SuperMarkdown.exe`。
- `SHA256SUMS.txt`：附件校验值。程序包尚未进行代码签名。

升级前保存旧窗口中的文档，再关闭旧版并运行新版。

## 更新

- 顶部操作集中到靠左的独立菜单行，提供“文件 / 编辑 / 查看 / 主题”；新建、保存、布局和模式也有快捷入口。路径单独显示，正文区域更清晰。
- “查看”支持文件目录、大纲、隐藏侧栏、可视/源码模式，以及单文件、双文件并排和预览源码同步布局。
- 代码和 Markdown 源码采用本地语法着色。代码区提供行号，支持 JavaScript、TypeScript、Python、HTML、CSS、JSON、Shell 等常见语言；其他文本仍可原样编辑。
- 选中多行，点击“多行输入”，输入 `#` 可同时加到每行最左侧，之后输入或删除仍同步。Esc 退出，Ctrl+Z 撤销。适用于 TXT、代码和 Markdown 源码；同步布局在右侧源码区操作。
- 左侧路径旁 ↑ 返回浏览目录的上一层，保留正在编辑的正文。再次点击正文或切换文件后，目录继续跟随当前文件。过时的目录读取不会覆盖手动导航。
- 界面采用扁平配色、圆角面板和轻量边框；四套主题为极简白（克莱因蓝点缀）、Dark 深色、暖奶油、科技灰。主题和侧栏视图在重启后保留，浮动菜单与正文同步配色。

## 验证与范围

验证覆盖真实键盘的多光标输入及中文文本、撤销/重做、CRLF 保存、JavaScript/Python 着色、双向同步、上级目录、四主题切换和跨进程偏好恢复；同时回归系统打开、拖拽、分屏、保存冲突与恢复草稿。

代码着色基于语言语法，不包含项目级语义分析或智能补全。真实中文输入法的完整候选与组合行为仍需人工体验确认；图片管理、查找替换等此前未完成的功能未在本次更新中补齐。
