# SuperMarkdown v0.3.1

新增正文缩放，并调整 Codex 与 Anthropic 两套主题。

## 下载与升级

- `SuperMarkdown-0.3.1-windows-x64-setup.exe`：Windows 64 位安装包，可沿用原安装目录直接升级。
- `SuperMarkdown-0.3.1-windows-x64.zip`：完整解压后运行 `SuperMarkdown.exe`。
- `SHA256SUMS.txt`：附件校验值。程序包尚未进行代码签名。

升级前保存文档并关闭旧版窗口，无需先卸载；本地文档与用户偏好保留。

## 正文缩放

- Ctrl + 向上滚轮放大、向下滚轮缩小，每次调整 10 个百分点。
- 菜单栏直接下拉选择百分比，支持 50%～300%，包含 100%、125%、150% 等常用值。
- Ctrl+0 恢复 100%；“查看”菜单也提供放大、缩小及恢复入口。
- 可视正文、Markdown 源码和普通代码文本同时调整，分屏两侧使用相同比例。工具栏和侧栏保持原尺寸。
- 缩放不改写文件、不产生未保存状态，也不改变撤销记录；重启后保留最后比例。

## 主题与界面

- 原浅色主题改为 **Codex 风格**：白色正文、浅灰侧栏、蓝色线条图标，选中文件与工具后以黑色强调。正文面板圆角与侧栏直边拼接，使用细分隔线和轻量标签。
- 原暖奶油主题改为 **Anthropic 风格**：暖奶油正文、米色侧栏、黑色及深灰图标，正文采用 Georgia / 宋体等系统衬线体；代码和源码保留等宽字体。
- 统一文件操作、目录和导航的本地线条图标；浮动菜单、模式选择和边框随主题协调。
- Dark 深色和科技灰仍可选择。旧版 `light` / `cream` 设置直接沿用，无需重新配置。

设计参考用户提供的 Codex 截图，以及 [Codex 官方产品介绍](https://openai.com/index/introducing-the-codex-app/)和 [Anthropic](https://www.anthropic.com/) / [Claude](https://claude.com/) 官方页面，按本地文档编辑的布局调整。

## 验证

检查真实 Ctrl+滚轮、Ctrl+0、百分比与边界、重启记忆、两侧字号、主题字体和图标；回归多行输入、源码同步、系统打开、拖拽、原编码保存、外部修改冲突与恢复草稿。字体使用系统字体回退，不依赖网络字体。完整中文输入法候选与组合行为仍需人工体验确认。
