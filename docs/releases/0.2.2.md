# SuperMarkdown v0.2.2

本版改进从系统打开文档后的目录浏览，加入本地文件分屏拖拽，并合并顶部工具行。

## 下载

- `SuperMarkdown-0.2.2-windows-x64-setup.exe`：Windows 64 位安装包。
- `SuperMarkdown-0.2.2-windows-x64.zip`：完整解压后运行 `SuperMarkdown.exe`。
- `SHA256SUMS.txt`：附件校验值。程序包尚未进行代码签名。

## 更新

- 双击 Markdown、软件中“打开”或拖入文件后，左侧显示该文件所在目录，可直接切换同级 Markdown、TXT、代码等可读取文本，并展开子文件夹。
- 支持从资源管理器拖入单个或多个本地文本文件。双文件并排时，拖到左侧就在左侧打开，拖到右侧就在右侧打开；拖动时高亮接收区域。
- 重复拖入已打开文件会复用标签页，保留未保存修改，不覆盖另一侧正文，也不把文件路径插入正文。
- 文件信息、新建/打开/保存/另存为、撤销/重做、显示布局合为一行。长路径省略并支持悬停查看完整内容，最小窗口宽度下也保持单行。
- 文件操作携带明确的目录上下文，避免切换目录后读取或创建同名文件时串到其他目录。
- 连续关闭标签页时按顺序处理请求，避免前一次草稿写入期间后一次关闭操作被忽略。

## 验证

在独立配置目录以真实进程及 OS 文件拖拽验证父目录展示、同级文本切换、左右拖入、多文件、重复打开保护和单行布局，并回归编辑保存与恢复。验证不改变用户文档和当前系统默认应用选择。

文件关联设置仍遵循 Windows 默认应用确认流程；ZIP 版不执行安装注册。图片资源管理、查找替换及更全面的中文输入法和 Markdown 兼容性仍在后续范围内。
