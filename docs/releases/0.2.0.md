# SuperMarkdown v0.2.0

本版补齐真实文件保存、关闭保护和草稿恢复。正常启动为写作工作区，应用源码从早期验证目录迁入 src/app/。

## 下载

- `SuperMarkdown-0.2.0-windows-x64-setup.exe`：Windows 64 位安装版。
- `SuperMarkdown-0.2.0-windows-x64.zip`：完整解压后运行 `SuperMarkdown.exe`。
- 两种包均自带运行环境，不需要安装 Node.js、pnpm 或 Electron。
- `SHA256SUMS.txt` 提供附件校验值。程序包尚未进行代码签名。

## 新增

- 新建 Ctrl+N，打开单个文件 Ctrl+O，保存 Ctrl+S，另存为 Ctrl+Shift+S。
- Markdown、TXT、代码等文本真实保存回磁盘；保留原文件编码、BOM 和 LF/CRLF 换行，另存为使用 UTF-8。
- 已保存基线与撤销历史独立；保存过程中继续输入不会被误标为已保存。
- 关闭标签页或系统窗口时提供保存、不保存、取消；保存失败及取消保存位置时保留文档。
- 后台保留未保存草稿，包含未命名文档；下次启动提示恢复，恢复后可继续编辑和保存。
- 检查外部修改，防止直接覆盖；可重新载入或另存为，源文件删除时也保留编辑内容。
- 正常启动不再默认展示验证样本。原有目录、链接、表格、可调分屏和双向编辑继续保留。

## 验证与当前边界

文件层 14 项、真实编辑器界面 138 项、正常启动 3 项和跨进程恢复 4 项检查全部通过。打包后的程序执行同一套界面及恢复验证。

图片资源管理、查找替换、更完整的 Markdown 往返兼容、中文输入法和精确光标定位仍需继续完善。恢复保留最近成功写入的快照，不能承诺断电时恢复最后每一个按键。本次在当前 Windows x64 环境验证，尚未完成全部目标 Windows 配置的兼容性验收。

**从 v0.1.0 升级前，请先复制保留旧窗口中的未保存内容。v0.1.0 本身没有正文保存和恢复能力，新版无法自动找回已经关闭的旧窗口内容。**
