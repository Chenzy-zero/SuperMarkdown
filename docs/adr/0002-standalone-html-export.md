# HTML 导出采用单文件静态内容

状态：2026-11-26 实现待验收，Issue #11。

首版采用单文件 HTML，而非 HTML+资源目录。内联固定 CSS 与受控图片，使输出不依赖源文件位置、网络或多文件提交，失败时只需原子替换单一目标。代价是 base64 体积与内存增长，因此限制图片数量/总量与最终输出大小。

复用本地 Vditor/Lute 解析，白名单重建静态 DOM，不复制编辑区的活动 DOM 或执行 Markdown HTML。公式/图表按源码降级并提示，后续可在相同导出接口增加安全静态渲染。读取图片使用独立 export-only API：授权已打开文档父目录内的相对图片，不放宽编辑器 `.assets` 读取接口。

导出独立于文档保存命令，不更新 opened_files、基线或历史。固定 HTML/CSS 返回值可供 #12 打印/PDF 复用，本轮不引入打印或浏览器下载。
