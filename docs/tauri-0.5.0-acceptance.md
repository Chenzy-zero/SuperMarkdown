# SuperMarkdown v0.5.0（Tauri 2）Windows 验收清单

本清单用于在真实 Windows 10/11 目标设备上完成 CI 无法覆盖的交互验收。**当前未执行的项目保持未勾选，不以 GitHub Actions 构建成功代替人工验收。**

## 测试前准备

- [ ] 记录 Windows 版本、系统架构、WebView2 Runtime 版本。
- [ ] 备份重要 Markdown 文档和 Electron 旧版用户数据。
- [ ] 关闭 Electron v0.4.0 与 Tauri POC，避免同时编辑同一文件。
- [ ] 确认安装包来源为 GitHub Release v0.5.0，并核对 SHA256SUMS.txt。
- [ ] 确认安装包未签名这一提示符合预期。

## 安装与启动

- [ ] 全新安装后可正常启动，窗口标题、图标和版本号正确。
- [ ] 安装后退出并重新启动，工作区和偏好设置正常。
- [ ] 普通用户权限下可安装/启动（如安装策略要求管理员权限，记录实际行为）。
- [ ] 安装目录、快捷方式、卸载入口正常。
- [ ] 在已有 v0.5.0 安装上再次运行安装程序，覆盖安装成功且用户文档不受影响。
- [ ] 卸载后行为符合预期；确认用户文档和 %APPDATA%\local.supermarkdown 是否保留。

## 编辑与中文输入法

- [ ] 可视编辑、源码编辑、两种模式切换正常。
- [ ] 使用实际拼音输入法输入中文，候选词选择、上屏、连续输入正常。
- [ ] 中文输入期间切换焦点、切换标签、撤销/重做，不出现重复字符或丢字。
- [ ] 常用快捷键（Ctrl+S、Ctrl+Z、Ctrl+Y、Ctrl+O、Ctrl+N、Ctrl+W）正常。
- [ ] 表格、列表、引用、代码块、公式及长文滚动显示正常。

## 文件操作与可靠性

- [ ] 打开文件夹、进入子目录、返回上级目录正常。
- [ ] 新建、打开、保存、另存为、关闭保护正常。
- [ ] 对同一文件重复打开时不会创建重复标签或覆盖未保存内容。
- [ ] 文件被外部程序修改后，保存冲突检测能阻止静默覆盖。
- [ ] 只读文件、无权限目录、磁盘空间不足或保存失败时，原文件不被破坏。
- [ ] 关闭未保存文档时，“保存 / 不保存 / 取消”行为正确。
- [ ] 关闭并重新启动后，未保存草稿恢复提示和恢复内容正确。

## 编码往返

准备包含中文、英文、特殊符号和换行的样本文件，逐项打开、编辑、保存，再用独立工具检查字节与内容：

- [ ] UTF-8
- [ ] UTF-8 BOM
- [ ] UTF-16 LE
- [ ] UTF-16 BE
- [ ] ASCII
- [ ] GBK
- [ ] GB18030
- [ ] Big5
- [ ] Windows-1252
- [ ] Latin-1

- [ ] 目标编码无法表示的字符会阻止保存，不会静默替换或破坏原文件。
- [ ] CRLF/LF 换行与末尾空行按预期保留。

## Windows 集成

- [ ] 在系统“默认应用”设置中将 .md 关联到 SuperMarkdown。
- [ ] .markdown、.mdown、.mkd 关联行为符合安装配置。
- [ ] 从资源管理器双击 Markdown 文件可打开正确文档。
- [ ] 软件已运行时再次双击文件，文件能转交给已有窗口。
- [ ] 从资源管理器拖入单个和多个文件，打开结果正确。
- [ ] 双窗格中拖到左右两侧，目标窗格正确。
- [ ] 有未保存修改时，通过系统文件打开或第二次启动不会丢失内容。

## WebView2 与离线环境

- [ ] 联网环境下已安装 WebView2 Runtime 的设备可正常运行。
- [ ] 公司标准镜像已包含 WebView2 Runtime，或软件分发流程能离线部署 Runtime。
- [ ] 在干净虚拟机快照中验证缺少 WebView2 Runtime 时的提示和恢复路径。
- [ ] 不要在日常工作设备上直接卸载 WebView2 Runtime 做缺失测试。

说明：v0.5.0 安装包使用系统 WebView2 Runtime，未内置 Fixed Runtime。没有可用 Runtime 的设备不能假设安装后可直接启动。

## 性能对照

在同一台机器、相同电源模式和相同样本文档下对比 Electron v0.4.0 与 Tauri v0.5.0：

- [ ] 冷启动时间（退出进程后测量，至少 5 次，记录中位数）。
- [ ] 空白工作区空闲内存（启动后静置 60 秒，至少 3 次）。
- [ ] 打开 1 MB、10 MB 文本/Markdown 文件的耗时。
- [ ] 长文滚动、编辑输入和切换可视/源码模式的流畅度。
- [ ] 安装包大小与实际安装目录大小。

不要只比较单次结果；记录机器配置、Windows 版本、WebView2 版本和样本文档大小。
