# Markdown 无损往返与表格编辑验收（Issue #4）

> 状态：第一阶段代码与自动化已提交；Windows WebView2 实际编辑、键盘输入和多窗格联合验收尚未完成。**不要把 CI 通过视为全部 DoD 已满足。**

## 文档与保护边界

1. **原文为真值**：打开、只浏览、滚动、切换可视/源码、切换标签或同步分屏，不触发 Markdown 重新序列化，不新增撤销记录，也不改变保存基线。原文件编码/BOM 和换行风格按既有保存接口保留。
2. **真编辑时有选择地归一化**：可视编辑依赖 Vditor 的 Markdown 序列化器；用户修改表格单元格、行、列、对齐方式时，允许更新该表格的 Markdown 结构。仅当表格语义（表头、行列内容、对齐）不变时，保留原表格的空格、横线宽度和换行风格。
3. **受保护块**：顶层 Mermaid 围栏与独占行公式的原始围栏、行尾空格等由 preserveProtectedBlocks 保护。用户试图从可视模式更改其内容时拒绝并提示切换源码；普通围栏中的数学示例不当作公式。
4. **光标映射**：新纯函数按可视文本与 Markdown 的相同片段*出现次数*定位，避免每次跳到重复段落的第一个匹配；支持 UTF-16 的 emoji 与 CRLF 偏移。使用 Selection 的 focus 而非 anchor 作为激活端。复杂嵌套 HTML、非字面文本映射及整体选区映射仍属待验收/后续工作。
5. **右侧分屏**：可视编辑的光标基于当前新序列化 Markdown 记录；源码编辑使用 CodeMirror selection.main.head，不再错误地把反向选区起点当作光标。

## 自动化与样本

- tests/fixtures/markdown-roundtrip.md：重复中文、非 BMP 字符、嵌套列表与任务、引用、链接、脚注、对齐表格、代码、Mermaid、LaTeX、YAML front matter。
- tests/fixtures/markdown-roundtrip-crlf.md：同类边界的真实 CRLF 与行尾空格。
- tests/markdown-caret.test.cjs：重复片段、Unicode、CRLF、链接及标题、无匹配回退。
- tests/markdown-tables.test.cjs：不相关正文修改保留表格原文、真实改单元格/增删行保留修改、两张表格独立保护、代码围栏排除和转义竖线。
- tests/markdown-roundtrip.test.cjs：复杂语料覆盖、无编辑不产生新历史、保护块、换行样本、跨模式 Undo/Redo。
- 运行 pnpm test；Windows 构建流程还需要 cargo test、cargo check 及 NSIS 打包。

## Windows 10/11 WebView2 人工验收（**未通过前勿关闭 Issue #4**）

| 场景 | 操作 | 期望 |
| --- | --- | --- |
| 无损打开/往返 | 打开 LF/CRLF 样本、切换可视↔源码 10 次、按 Ctrl+S、关闭重开、对比原文件字节 | 无改动的文件原文及编码/BOM 不变；无“未保存”状态 |
| 重复中文光标 | 将光标放到三处相同句子的最后一处，切换源码再返回可视 | 光标不跳回第一处，文档不变 |
| 反向选区 | 从末尾向前选中文字后切换模式；双文件左右重复 | 源码采用真实 focus 端，不误覆盖文本 |
| 表格单元格 | 进入表格，修改多个单元格的中文与数字，再切换源码 | 仅实际编辑的单元格变化；未编辑表格格式不被重写 |
| 插入行/列 | 使用 Vditor 表格工具栏添加/删除行、列，并反复撤销/重做 | 列数/行数与 Undo 步骤符合用户操作，不丢正文 |
| 表格键盘 | 在单元格使用 Tab / Shift+Tab、Enter，边界处操作 | 可移动焦点且不越界修改原文；若 Vditor 本身不支持某键，记录为待改缺口 |
| Mermaid、LaTeX | 在普通正文输入，检查围栏、双空格、公式没有变化 | 保持原始字节；源码编辑保护块后内容可更新 |
| 分屏/双文件 | 左侧可视与右侧源码同步，另测双文件右侧可视，重复撤销 | 同篇文档共享历史，两篇文档不会交叉覆盖 |
| 中文输入法 | 拼音/微软五笔组合、连续输入、候选选择、撤销和回退 | 不丢字、不触发非预期 Undo；人工记录实际系统与 IME 版本 |
| 异常恢复 | 编辑复杂表格后不保存，重启恢复草稿，并模拟磁盘外部更改 | 无静默覆盖，仍可恢复至最新用户快照 |

## 尚未覆盖的行为
