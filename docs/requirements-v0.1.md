# SuperMarkdown 首版需求确认稿

状态：2026-11-14 已完成逐项及整体确认；建议验收样本已暂定采用。

修订：根据后续补充，首版文件浏览范围扩大到工作文件夹中的各类文本文件；代码文件的语法高亮与风格化呈现列入下一期。

2026-11-15 补充：目录右键操作与新建 Markdown、双文件并排、同文档预览与源码双向同步编辑。

## 1. 目标与边界

首先服务于开发者本人的 Windows Markdown 写作。主要在排版后的正文中直接编辑，必要时快速切换到源码模式。

Typora 和 Markdown All in One 作为功能参考，具体范围以本文为准。实际文档类型、规模和当前工具的具体痛点尚未提供。

## 2. 界面与文档导航

- 正文居中、留白宽裕、限制阅读宽度，长文连续滚动。
- 上方提供简洁工具栏及多文档标签页。
- 左侧提供“文件 / 大纲”标签页：“文件”展示打开文件夹的目录树，点击文件进入编辑；“大纲”展示当前文档的标题层级，点击标题跳转到正文对应位置。
- “打开文件夹”（用户所说的导入文件夹）选择一个本地工作文件夹，直接浏览原目录，不复制或迁移文件。可展开子文件夹，浏览其中的 Markdown、TXT、代码、配置、日志和其他文本文件，包括无扩展名文本；不以固定的文本扩展名白名单限制浏览。
- Markdown 文件首次打开时默认使用可视编辑模式；其他文本文件使用纯文本模式，原样显示文字、缩进和语法符号，不套用 Markdown 排版。
- 纯文本文件不提供 Markdown 模式切换及标题大纲；已打开文件切换标签页时保留各自的编辑模式、内容与位置。
- 点击已打开的文件时，切换到已有文档标签页。
- 切换文档标签页时，保留各篇文档的未保存修改和编辑位置。
- 未保存修改以标签页标记表示，关闭时遵循保存提示规则。
- 每个文件标签页提供关闭按钮，并支持右键关闭当前、其他、右侧或全部标签页，以及复制完整路径、在文件夹中显示。关闭标签页只移除打开状态，不删除磁盘文件。
- 宽窗口下编辑滚动区占满可用正文区域，正文保持居中与合适的阅读宽度；目录字体与浮动菜单操作区需便于辨认和点击。
- 大纲跳转为目标标题预留顶部空间，并收起旧浮动菜单，防止标题被遮挡。
- 工具栏悬停提示需完整显示，不能被正文容器或上方工具栏遮挡。
- 左侧文件目录支持右键打开、在右侧打开、新建 Markdown 文件、复制完整路径、在文件夹中显示及刷新。可通过侧栏按钮在工作文件夹根目录新建 `.md`，或右键子目录在该目录新建；同名文件不得被覆盖。
- 正文支持双文件并排，两侧可分别编辑；可通过目录右键在右侧打开文件，或标签页右键将文件移到右侧显示。
- Markdown 支持预览源码同步布局：左侧可视编辑，右侧源码编辑，两侧修改即时同步，撤销与重做共享同一文档历史；点击任一侧选择当前编辑区域。
- `Ctrl+W` 关闭当前编辑的文档，并遵循未保存提示规则；双文件并排时关闭当前侧文件，同文档同步布局则关闭该文档的两个视图。没有打开文档时保留窗口。
- Markdown 可视编辑与源码采用相同的居中阅读宽度及左右留白规则；分屏时按各自窗格宽度自适应。
- 双文件并排与预览源码同步均支持拖动中央竖线调整左右宽度，两侧保留可用空间，双击恢复等宽；本次窗口内切换布局保留比例。
- 从系统双击或“打开”进入文档后，左侧显示其所在目录，并支持切换同级各类文本文件、展开子目录。
- 支持把本地 Markdown 或其他可读取文本拖入软件；双文件并排时按落点打开到左侧或右侧，多文件可同时拖入，重复文件复用标签并保留未保存修改。
- 文件信息、文件操作、撤销重做和布局选择合并为一行；长路径省略且可悬停查看完整内容，最小窗口下仍可操作。

## 3. 编辑模式与排版范围

### 可视编辑模式

- 直接在排版后的正文中编辑。
- 支持 Markdown 快捷输入，例如行首输入 `# ` 转为标题，输入 `**文字**` 后呈现加粗。
- 语法生效后隐藏标记；光标进入相应文字或段落时保持排版效果。
- 工具栏可点击设置格式。

### 源码模式

- 单文件布局支持整篇可视编辑与源码模式切换及快捷键；也可选择同时显示两种编辑视图。
- 切换时保留当前编辑位置，修改源码后可切回原处继续写作。
- 两种模式间切换后，保留同一文档的撤销、重做记录。
- 当前切换快捷键保留 `Ctrl+Shift+M`；`Ctrl+Shift+Z` 因与重做惯例冲突，继续用于重做。

### 首版排版

- 一级至六级标题、段落、分隔线。
- 粗体、斜体、删除线、行内代码。
- 有序列表、无序列表、任务清单、引用。
- 链接、图片。
- 代码块，支持语言选择与语法高亮。
- 表格，具体操作见下一节。

### 编辑辅助

- `Ctrl+F` 查找当前文档。
- `Ctrl+H` 替换，支持逐个替换与全部替换。
- `Ctrl+Z` 撤销、`Ctrl+Y` 重做，覆盖文字、格式和表格编辑。

## 4. 表格

- 从工具栏选择行数、列数，快速创建表格。
- 点击单元格直接编辑。
- 右键菜单支持增加和删除行或列，以及删除整张表格。
- `Tab` / `Shift+Tab` 切换单元格；最后一个单元格按 `Tab` 新增一行。
- 支持列的左对齐、居中和右对齐。

## 5. 文件、图片与兼容

- Markdown 文档保存为普通本地 `.md` 纯文本文件，可由其他编辑器继续打开。
- 支持打开单个 `.md` 文件及整个文件夹。
- 工作文件夹内的其他文本文件也可打开和编辑，保存时保留原文件扩展名及文本内容；代码文件不转换为 Markdown 文件。
- 新建文档后选择保存位置，`Ctrl+S` 保存。
- 图片支持粘贴截图、拖入本地图片及通过工具栏选择图片。
- 新插入的图片复制到 `.md` 文件同级的 `assets` 文件夹，正文使用相对路径。
- 新文档尚未保存时先临时保留图片，首次保存时再一并存入对应位置。
- 已有文档中暂不支持渲染的内容（例如公式、Mermaid 图）在可视编辑模式显示为原始源码块，需要修改时进入源码模式。
- 编辑其他正文并保存后，暂不支持渲染的片段仍原样保留。
- 悬停超链接时，在鼠标指针右下方以浮层显示实际目标 URL 或解析后的本地路径，浮层随鼠标移动；离开链接、滚动正文或切换文档时收起，靠近窗口边缘时调整位置以保持可见。浮层不拦截鼠标操作。点击原链接后，本地可读取文本文件由本工具打开，HTTP/HTTPS 网页交由默认浏览器打开；相对路径以当前文档位置为基准，文档内标题链接在当前文档跳转。

## 6. 保存、恢复及外部变更

### 手动保存与恢复草稿

- `Ctrl+S` 将修改写入当前原始文本文件，包括 Markdown、TXT 和代码等文本文件。
- 后台自动保存恢复草稿，包含尚未命名的新文档。
- 关闭存在未保存修改的文档时，提供“保存 / 不保存 / 取消”。
- 意外退出后，下次启动提示恢复未保存内容。

### 外部文件变更

- 当前文档没有未保存修改：自动载入磁盘新内容，并保留阅读位置。
- 当前文档也有未保存修改：提示选择重新载入磁盘版本，或将当前内容另存为。
- 原文件被移动或删除：保留当前内容，保存时提示选择新位置。

## 7. 运行与交付

- 支持 Windows 10 / 11，64 位。
- 本地文档编辑、图片处理和草稿恢复均可离线使用。
- 首版提供常规安装包。

## 8. 已确认留到后续版本

- 表格合并、拆分单元格。
- 数学公式（LaTeX）与流程图（Mermaid）的输入、渲染。
- PDF、Word、HTML 导出及打印。
- 跨文件搜索。
- A4 纸张分页、页眉页脚。
- 便携版。
- 按代码文件语言类型提供语法高亮、配色等简单风格化显示。Markdown 正文中代码块的高亮仍按首版既定范围处理。

## 9. 验收样本与场景

### 样本

暂采用已确认的建议样本：约 5000 字、3 张图片、2 个表格、少量代码的中文文档。此为验收基线，并非用户提供的实际文档情况，也不是文档大小上限；后续可根据实际文档调整。

### 基于已确认需求的验收步骤

1. 打开含 Markdown、TXT、代码和无扩展名文本的本地文件夹，展开子目录并点击文件，通过文档标签页切换。Markdown 默认可视打开并提供大纲跳转，其他文件默认纯文本显示，文字中的 Markdown 符号不会被排版。
2. 在可视编辑模式输入中文、标题、列表、加粗等内容，确认即时排版与语法标记隐藏符合约定。
3. 切换到源码模式修改局部内容，再切回原处；检查内容、编辑位置及撤销、重做记录。
4. 创建表格，编辑单元格，增删行列，设置对齐，验证 `Tab` / `Shift+Tab` 与末尾新增行。
5. 分别粘贴截图、拖入图片及从工具栏选择图片；保存后检查资源位置、相对路径及重新打开的显示结果。
6. 在未保存的新文档中插入图片并输入正文，首次保存后确认正文和图片均可重新打开。
7. 验证当前文档查找、逐个替换与全部替换，以及文字、格式、表格操作的撤销和重做。
8. 打开含暂不支持渲染片段的文档，编辑其他正文并保存，比较这些片段是否原样保留。
9. 检查关闭未保存文档时的三个选项；模拟意外退出后恢复有名和未命名文档的草稿。
10. 分别在没有、有未保存修改时从外部修改文件，验证载入与冲突提示；移动或删除原文件后验证另存处理。
11. 安装后离线执行本地写作、图片处理、保存和恢复流程。
