# 项目起点

## 方向与协作

SuperMarkdown 首先服务于开发者本人，目标是在 Windows 上直接编辑排版后的 Markdown，并支持快速切换源码模式。功能参考 Typora 和 Markdown All in One。

开发协作默认使用简体中文，从用户目标、约束与事实出发分析问题，区分假设并验证关键未知。具体协作规则见根目录 AGENTS.md。

任务与规格使用 Chenzy-zero/SuperMarkdown 的 GitHub Issues，操作约定见 docs/agents/issue-tracker.md。

## 需求入口

[首版需求确认稿](requirements-v0.1.md) 是功能范围、已确认行为、延期能力及建议验收场景的统一记录。开始选型或实现前读取该文件。

功能与界面条目及汇总稿已于 2026-11-14 整体确认。暂采用稿中的建议验收样本；用户尚未提供真实写作样本，数值化性能目标待原型实测后确定。

后续已补充确认：左侧支持打开真实工作文件夹及子目录；Markdown 默认可视编辑，TXT、代码等其他文本文件以纯文本打开，代码文件的语言风格化显示留到下一期。

2026-11-15 继续补充：目录提供右键操作及直接新建 `.md`；正文支持双文件并排，以及同篇 Markdown 左侧可视编辑、右侧源码编辑并双向同步。

分屏宽度支持拖动调整；Markdown 两种模式采用统一的居中留白，`Ctrl+W` 关闭当前文档并保留未保存提示。

## 技术决策状态

0.2.0 起进入应用实现，源码迁入 src/app/。沿用 Electron 与已接入的 Vditor，保留现有编辑功能，并补齐新建、打开、真实保存、另存为、关闭保护、草稿恢复及外部修改处理。文件保存与文档历史由应用管理，避免被编辑内核绑定。

文件可靠性行为和实测见 [保存与恢复](saving-and-recovery.md)。图片资源管理、查找替换、完整中文输入法与更广泛的 Markdown 兼容仍未完成；不因版本打包就视作全部首版需求已经验收。项目许可证仍未确定。

0.2.1 补齐安装文件关联、系统双击启动及已运行窗口中的文件转交，并提供 Windows 默认应用设置入口。

0.2.2 增加系统打开文档后的父目录浏览、本地文件按分屏落点拖拽打开，以及单行文档操作区。

0.2.3 将目录跟随扩展到标签页切换与左右编辑区域激活，并防止旧的异步读取结果覆盖当前目录。

选型依据、实测结果与未验证项见 [技术评估](technical-evaluation.md)；当前运行方式见 [应用说明](../src/app/README.md)。

领域术语写入根目录 GLOSSARY.md，重要决策按需写入 docs/adr/。

0.3.0 增加独立的靠左菜单行、目录上一级、代码语法着色与多行同时输入，并提供四套可记忆的主题。代码和源码编辑视图采用 CodeMirror，文档保存与撤销仍由应用管理。

0.3.1 增加 Ctrl+滚轮、百分比下拉与 Ctrl+0 的全局正文缩放（50%～300%，用户偏好持久化）；浅色与暖奶油主题分别调整为 Codex 风格和 Anthropic 风格，并统一线条图标、选中状态和圆角面板拼接。

2026-11-16，0.4.0：状态栏增加当前文件总行数与总字符数，提供十种编码的转换保存及重新读取入口；双文件并排支持未保存内容的只读差异对比、新增/删除/修改统计和差异跳转。

2026-11-19，0.5.0 转正准备：Tauri 2 后端从 experiment/tauri-poc 重放到 main，保留 MIT 许可证；正式标识改为 `local.supermarkdown`，应用与 Cargo 包版本统一为 0.5.0，并提交 Cargo.lock 固定 Rust 依赖。Electron 0.4.0 仍是正式发布线；Tauri 通过 docs/tauri.md 中的转正门槛前，不改变发布流程。

2026-11-23，Tauri 0.5.0 Windows x64 正式版发布：基于 `feature/tauri-promotion` 的成功 Windows CI 构建产物，Rust 8 项测试、Node.js 测试、cargo check 与 NSIS 打包通过。人工验收项仍需后续完成；安装包未签名并依赖 WebView2 Runtime。源码分支暂未合并至 main。

## 2026-11-23：Tauri 正式主线

Tauri v0.5.0 已发布为 Windows x64 最新稳定版。`feature/tauri-promotion` 合并至 `main` 后，Tauri 作为唯一正式发行线；Electron v0.4.0 历史 Release 保留，Electron 宿主与回归测试暂时保留，不再发布新的 Electron 正式包。真实 Windows 中文输入法、文件关联、拖放、WebView2 离线部署和性能对照按 `docs/tauri-0.5.0-acceptance.md` 继续验收。
